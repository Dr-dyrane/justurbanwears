# Historical Studio UX proof

These captures are the historical ADR 0041 baseline, not current Studio release
acceptance. In particular, the Home work-card grid and contextual FABs shown
below are retired. Do not reproduce them in new UI. Current navigation placement
is recorded in [ADR 0044](../../adr/0044-studio-home-service-registry-and-stack-navigation.md).

The original capture record reports a local 390 × 844 CSS viewport for the
baseline and a desktop acceptance viewport for the later guide captures. These
are browser screenshots, not evidence of real iOS keyboard or Safari behavior.
They use existing approved catalogue records; no fake production garment or
model was created for documentation.
